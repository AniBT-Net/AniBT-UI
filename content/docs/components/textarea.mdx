## 用法


## 状态

<ComponentPreview name="textarea-states" />

材质、悬停、聚焦、出错、只读、禁用都和 [Input](/docs/components/input) 一样。不同的只有高度：`field-sizing-content` 让文本框从两行起随内容长高，用户还能往下拖高。需要固定高度时给 `className="h-40 field-sizing-fixed"`。

收 Markdown 的地方用 Markdown 编辑器；公开页按纯文本显示的简介（番剧简介、字幕组简介）用普通文本框。
