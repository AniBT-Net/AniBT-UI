## 用法

```tsx title="用法"
import { Kbd, KbdGroup } from "@/components/ui/kbd"

<Kbd>⌘K</Kbd>

<KbdGroup>
  <Kbd>Ctrl</Kbd>
  <Kbd>B</Kbd>
</KbdGroup>
```

键帽是 `muted` 底、一圈 `border` 细边，底边多一道 `input` 色的 1px，像按下去的键；字是 Fredoka 600/12。它只是提示，不可点击（`pointer-events-none`），绑定快捷键是页面自己的事。
