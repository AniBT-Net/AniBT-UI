## 显示键

右端是 24px 的安静方块，悬停是粉色淡底。它一直有名字——「显示密码」或「隐藏密码」（`showLabel` / `hideLabel`）——并用 `aria-pressed` 报告状态，键盘和读屏都分得清。字符是否明文显示是这个组件自己的状态，外面不需要知道。

注册和改密码时给 `autoComplete="new-password"`，登录时给 `"current-password"`，密码管理器才认得出。自动大写、自动更正和拼写检查已经关掉。
