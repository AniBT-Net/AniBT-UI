## 用法

```tsx title="用法"
import { Progress } from "@/components/ui/progress"

<Progress value={62} aria-label="上传进度" />
```

一种颜色一种职责：`tone="water"`（默认）是蓝色，表示进行中；`tone="candy"` 给读者自己在填的目标（本月发布、追番进度）；`tone="ok"` 表示已经完成。`size` 有 `compact`（6 高，放在行里）、`default`（10 高）和 `lg`（14 高）。

## 标签与数值

<ComponentPreview name="progress-label" />

有子元素时，进度条变成 Base UI 的样子：上面一行是 `ProgressLabel` 和 `ProgressValue`，下面是轨道。`ProgressValue` 不写内容时自己算：`max` 是 100 时显示百分比，否则显示 `3 / 5`；`format` 可以强制其中一种。

`value={null}`（或不传）是不确定进度：一小段填充沿着轨道来回滑动，减少动态效果时停住。
